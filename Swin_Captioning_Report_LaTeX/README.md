# Swin Transformer Image Captioning on ROCOv2: LaTeX source

Project review report (version 2), Amrita School of Artificial Intelligence.

## Contents

- `main.tex`: preamble, cover page and table of contents; it includes the chapters.
- `chapters/`: one `.tex` file per chapter or part of a chapter, in reading order.
- `figures/`: all figures (PNG, 300 dpi).
- `main.pdf`: the compiled report.

## How to compile

The report uses XeLaTeX, for Unicode text and the TeX Gyre fonts.

- **Overleaf:** upload this folder (or the zip), open Menu, and set Compiler to **XeLaTeX**.
- **Local, with TeX Live or MiKTeX:** `latexmk -xelatex main.tex`, or run `xelatex main.tex` twice.
- **Local, with Tectonic:** `tectonic main.tex`.

Equation numbers are written explicitly with `\tag{...}`. Figure and table numbers are generated by LaTeX and match the references in the text.
